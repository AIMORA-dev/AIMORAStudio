# GUI040 — Julia Service Lifecycle and Generated C++ Protocol

GUI040 connects the native C++/Qt client boundary to the public `AIMORAService` protocol
without embedding Julia or copying engineering semantics into C++.

## Implemented Studio surface

- generated C++ method and error identifiers copied byte-for-byte from the canonical
  `AIMORAService` generator output;
- bounded `AMR1` control and binary frame encoding/decoding;
- strict request and response envelopes;
- authenticated `QLocalSocket` client;
- `QProcess` lifecycle controller with one-use token files, startup timeout, graceful
  shutdown, forced cleanup, explicit restart, and bounded automatic restart;
- capability negotiation and typed failures;
- request cancellation and bounded pending-request accounting;
- opaque project and artifact reference methods;
- bounded binary result-window handling;
- worker start, status, and stop requests;
- an application `--service-smoke` journey;
- mock-service, codec, authentication, lifecycle, restart, worker, binary, and negative tests;
- a committed CMake protocol-source verification script.

## Canonical ownership

The schema and generated binding authority remain in:

```text
AIMORAPlatform/AIMORAService/schema/service_protocol.json
AIMORAPlatform/AIMORAService/tools/generate_cpp_bindings.jl
```

AIMORAStudio owns only the generated client copy and native transport/lifecycle behavior.
Physical models, project semantics, study contracts, result validity, and solver kernels
remain in Julia owners.

## Application smoke command

The desktop executable accepts a trusted service program and its fixed startup arguments:

```text
aimora-studio --service-smoke \
  --service-program julia \
  --service-argument --startup-file=no \
  --service-argument --project=/path/to/AIMORAService \
  --service-argument /path/to/AIMORAService/bin/aimora-service.jl \
  --service-root /path/to/allowed/projects
```

The application creates the endpoint and private token file, starts the service, performs the
authenticated handshake, sends a ping, requests clean shutdown, and returns a nonzero exit
status on failure.

## Scope boundary

GUI040 does not parse an AIMORA project into C++, edit engineering assets, run a production
study, expose private solver internals, or interpret scientific result arrays. Those are
connected through later canonical project, inspector, study, and result packets.
