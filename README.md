# AIMORAStudio

`AIMORAStudio` is the minimal public TypeScript monorepo reserved for browser, desktop, and VS Code clients of the versioned `AIMORAService.jl` protocol. This scaffold contains only the protocol package and no canvas, hidden engineering model, solver code, telemetry, activation, or feature lock; future applications must edit the same canonical Julia-owned model.
